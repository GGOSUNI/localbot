LocalBot 간편 로그인 서버 - 브라우저로 배포하기 (Node 설치 필요 없음, 10분)
=====================================================================

1) https://dash.cloudflare.com/sign-up 에서 무료 가입 (이미 있으면 로그인)

2) 왼쪽 메뉴 "Workers & Pages" -> "Create" -> "Create Worker"
   - 이름: localbot-relay  -> "Deploy"
   - 만들어지면 "Edit code" 클릭
   - 왼쪽 파일(worker.js)의 내용을 전부 지우고,
     이 폴더의 worker.js 내용을 전부 복사해서 붙여넣기 -> 오른쪽 위 "Deploy"
   - 주소 확인: https://localbot-relay.XXXX.workers.dev

3) 치지직 개발자센터 https://developers.chzzk.naver.com 에서 애플리케이션 등록
   - 이름: LocalBot 처럼 (치지직/chzzk/네이버/naver 는 넣을 수 없음)
   - 로그인 리디렉션 URL: https://localbot-relay.XXXX.workers.dev/callback
   - API 권한: 유저 정보 조회, 채팅 메시지 쓰기
   - 등록 후 Client ID 와 Client Secret 확인

4) Cloudflare 로 돌아가서 localbot-relay -> "Settings" -> "Variables and Secrets" -> "Add"
   - Type: Secret,  Name: CHZZK_CLIENT_ID,      Value: (Client ID)
   - Type: Secret,  Name: CHZZK_CLIENT_SECRET,  Value: (Client Secret)
   - "Deploy" (저장)

5) 브라우저에서 https://localbot-relay.XXXX.workers.dev 를 열어서
   {"ok":true,"service":"localbot-relay"} 가 보이면 성공.
   이 주소를 Claude 에게 알려주세요. (Client Secret 은 알려주지 마세요)
