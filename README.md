# LocalBot (가칭)

치지직 스트리머를 위한 **로컬 자립형** 봇. `LocalBot.exe` 하나로 실행되고, 외부 서버나 API 키 없이 동작합니다.

핵심 기능: **절대 고장 안 나는 신청곡 스테이션** · **손쉬운 룰렛** · **완벽한 스탠드얼론**
설계: [docs/DESIGN.md](docs/DESIGN.md)

## 현재 상태

- **딸깍 연결**: 더블클릭 → 치지직 채널 주소 붙여넣기 → 끝. 콘솔 창 없음, 다음 실행부터 자동 연결
- **신청곡 + 스테이션**
  - `!신청곡 <유튜브 링크>`, 후원 메시지 링크 자동 신청(금액 이상이면 우선 재생), 대시보드 직접 추가
  - 정책: 최대 길이, 1인 대기 수, 중복·최근곡 금지, 권한, 승인 모드, 금지 키워드
  - 스테이션: YouTube 링크 목록 / **내 음악 폴더** / 자동 "인기 신청곡". 셔플(최근 N곡 재생 금지)·순서대로
  - 고장 대책: 신청 시 + 재생 전 2단계 검증, 멈춤 워치독(재로드→스킵), OBS 재시작·워커 크래시 후 같은 위치 재개,
    YouTube 연속 실패 시 로컬 비상 스테이션, 플레이어 이중 재생 방지, 되돌리기
  - 채팅 명령: `!신청곡` `!현재곡` `!대기열` `!신청취소` / 매니저 `!스킵` `!신청마감` `!신청오픈` `!일시정지` `!재생` `!볼륨`
- **룰렛**: 한 줄 문법(`항목 x5 [재고 1]`), 실시간 원판 미리보기·확률, 템플릿 3종, 금액당(잔액 이월·상한)/정확 금액/수동,
  서버에서 암호학적 난수로 결과 확정 후 연출, 10연차 카드, 무대 큐, 벌칙 체크리스트, 실측 통계, 공유 코드
- **OBS 오버레이**: `/o/player`(소리), `/o/nowplaying`, `/o/roulette` — 오버레이 전용 키, 재발급 가능
- 테스트 82개 (신청곡 장애 시나리오 카오스 테스트 포함)

## 개발

```bash
bun install
bun run dev        # http://127.0.0.1:7777 (콘솔에 접속 주소 표시)
bun test
bun run typecheck
bun run build:win  # dist/LocalBot.exe
```

환경 변수: `LOCALBOT_PORT` `LOCALBOT_HOME` (데이터 위치) `LOCALBOT_NO_BROWSER=1`
