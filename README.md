# 🤖 LocalBot — 치지직 스트리머용 로컬 봇

**`LocalBot.exe` 하나, 채널 주소 붙여넣기 하나로 끝.**
서버·회원가입·API 키 없이 내 PC에서 돌아가는 치지직 봇입니다. 신청곡, 자동 스테이션, 룰렛, 후원 TTS, OBS 오버레이를 한 번에.

> ⬇ **[LocalBot v0.7.0 다운로드 (Windows)](https://github.com/GGOSUNI/localbot/raw/download/LocalBot-v0.7.0-win-x64.zip)** — zip을 풀고 `LocalBot.exe`를 더블클릭

## 이런 걸 합니다

### 🎵 절대 끊기지 않는 신청곡
- 시청자가 `!신청곡 아이유 밤편지` 처럼 **곡 이름**으로 신청 → 유튜브에서 찾아서 대기열에 (링크도 OK)
- 후원 메시지에 `!신청곡 곡이름` → 자동 신청 + 일정 금액 이상이면 **우선 재생**
- 최대 길이, 1인 대기 수, 중복·최근곡 금지, 구독자 전용, 승인 모드, 금지 키워드
- **고장 대책**: 재생 못 하는 영상은 차례 오기 전에 미리 빼기 · 멈추면 다시 불러오고 안 되면 다음 곡 · OBS를 재시작해도, 봇이 꺼졌다 켜져도 **같은 곡 같은 위치에서 이어서** · 실수로 스킵해도 **되돌리기**

### 🎧 자동 스테이션 (유튜브 알고리즘)
신청곡이 없으면 **시청자가 신청한 노래들과 비슷한 곡**을 유튜브 믹스에서 찾아 라디오처럼 이어서 틀어 줍니다. 설정할 것 없음.
스킵한 가수는 한동안 빼고, 같은 가수가 3번 연달아 나오지 않게.

### 🎰 30초 만에 만드는 룰렛
- 한 줄에 항목 하나 — `꽝 x5`(가중치), `치킨 [재고 1]`(한정)
- 후원 **금액당 N회** / **정확한 금액** / 수동 · 잔액 이월 · 10연차 카드 연출
- 결과는 서버가 먼저 정하고 원판은 그 칸에 멈추도록 연출만 → 새로고침해도 결과 안 바뀜
- 벌칙 체크리스트, 실제 당첨 통계, **공유 코드**로 다른 스트리머와 룰렛 주고받기

### 🤖 봇 답장 (치지직 공식 연결)
대시보드에서 **"치지직으로 로그인"** → 동의. 키 입력 없이 봇이 채팅방에 직접 답합니다.

### 🔊 후원 TTS
후원이 오면 **윈도우 내장 한국어 목소리**로 스피커에 바로 읽어 줍니다 (OBS는 데스크톱 오디오에 그대로 잡힘, 추가 설정 없음).
- 읽는 동안 노래 소리 자동으로 줄이기 · 하나씩 순서대로
- 최소 금액, 읽는 문장(`{user}님 {amount}원 후원. {message}`), 최대 길이, 목소리·빠르기·음량
- 링크·이모티콘 빼기, `ㅋㅋㅋㅋㅋ` 반복 줄이기, 금지어는 "삐", `!신청곡` 같은 명령어 메시지는 안 읽기
- 원하면 OBS에 **후원 알림 카드** (`/o/alert`)

### 📺 유튜브 재생 — 막히는 곡 없음
신청곡은 LocalBot이 화면 밖에 숨겨 둔 엣지/크롬 창에서 진짜 youtube.com으로 재생하고, 영상은 **대시보드 안에** 보여 줍니다.
애니 OP·음반사 곡처럼 **다른 사이트 재생이 막힌 영상(오류 150)도 전부 재생**됩니다. 소리는 데스크톱 오디오로 그대로 방송에 나갑니다.

### 🖼 OBS 오버레이
현재 곡 · 룰렛 · 후원 알림 — 대시보드에서 주소 복사해서 브라우저 소스로 추가

## 완전 스탠드얼론
- 설치 없음, 런타임 설치 없음 (단일 exe) · 모든 데이터는 exe 옆 `data\` 폴더 → 폴더째 옮겨도 그대로
- 개발자 서버 없음 — 이 프로젝트가 사라져도 계속 동작
- 봇이 죽어도 1초 안에 스스로 다시 켜짐 · 방송 시작 때마다 자동 백업

## 필요 사양
- Windows 10/11 64비트
- 치지직 채널

## 알려진 한계
- 채팅·후원 수신은 로그인 없이 공개 채팅을 읽는 방식이라, 치지직이 구조를 바꾸면 업데이트가 필요할 수 있습니다.
- 리허설·비공개 방송은 외부에서 볼 수 없어 연결되지 않습니다 (방송을 켜면 10초 안에 자동 연결).
- 유튜브 임베드 광고는 제어할 수 없습니다.
- 아직 코드 서명 전이라 "Windows의 PC 보호" 경고가 뜰 수 있습니다 → 추가 정보 → 실행.

## 개발

```bash
bun install
bun run dev        # http://127.0.0.1:7777
bun test           # 132개 (신청곡 장애 상황 카오스 테스트 포함)
bun run typecheck
bun run build:win  # dist/LocalBot.exe
```
